# Glossary

| Term | Meaning |
|------|---------|
| **Deck** | One importable question bank (title, id, language, list of questions). |
| **Question** | One card in a deck; has a template type and answer key. |
| **Template** | Question shape and grading rule (`single`, `multi`, `order`, `match`, `cloze`, `reveal`). |
| **Card loop** | Prompt → reveal controls → submit → feedback → next. |
| **Think phase** | First view of the prompt without answer controls. |
| **Reveal controls** | Second interaction that shows options / tiles / pairs / blanks (not the key yet). |
| **Grade** | Correct / incorrect (or self-reported for `reveal`). |
| **Mix** | Study session drawing from multiple selected decks. |
| **Progress** | Per-question local stats for a deck. |
| **formatVersion** | Integer on the deck file declaring the interchange schema. |
| **Grading fixture** | Abstract input/expected-output case shared by Android and web tests. |
